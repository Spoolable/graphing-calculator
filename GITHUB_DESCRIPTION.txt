Graphing calculator built with TypeScript, Canvas, and Vite — Cartesian, polar, and
parametric graphs, automatic and shared-variable sliders, symbolic derivatives, curve
tracing, zoom/pan, seven color themes, and localStorage persistence. Zero runtime
dependencies. Runs in the browser or as a standalone desktop app (portable Windows .exe /
Linux AppImage).
